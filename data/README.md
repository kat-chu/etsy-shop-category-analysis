# Data

The data is not stored in this repository because it is about 2.6 GB.

Download these three files from the [ASHRAE Great Energy Predictor III competition](https://www.kaggle.com/c/ashrae-energy-prediction/data) on Kaggle:

- `train.csv` (hourly meter readings)
- `building_metadata.csv` (building type, size, year built, floors)
- `weather_train.csv` (hourly weather by site)
